# NORTHLINE

Адаптивный одностраничный концепт премиальной студии автомобильного
детейлинга в Москве.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
pnpm install
pnpm dev
```

После запуска сайт доступен по адресу `http://127.0.0.1:3000`.

## Проверки

```bash
pnpm typecheck
pnpm lint
pnpm build
```

Форма работает только в демонстрационном режиме: проверяет поля, но не
отправляет и не сохраняет данные. Проекты, отзывы, цены, контакты и визуалы
созданы для учебного макета и не описывают действующую студию.
